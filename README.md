## 📖 Description

A modern and responsive **Wanderlust Travel website** built using **HTML, CSS, and JavaScript**. The project focuses on creating an engaging travel experience with destination-focused content, visually appealing layouts, responsive design, and interactive user interface elements.

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/SwarajThakre/wanderlust-travel.git
```

### 2. Navigate to the project directory
cd wanderlust-travel

### 3. Run the website

Open index.html directly in your browser.

For development, you can use the Live Server extension in VS Code and click Go Live.

Requirements
A modern web browser
VS Code (recommended)
Live Server extension (optional)

No additional dependencies or package installation are required.
